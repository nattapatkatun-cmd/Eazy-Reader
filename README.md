# Eazy Reader — แอปอ่านหนังสือแบบ PWA

แอปอ่านหนังสือที่ทำงานในเบราว์เซอร์ ติดตั้งลงหน้าจอหลักได้ และอ่านออฟไลน์ได้
ไฟล์ทั้งหมดเก็บอยู่ในเครื่องผู้ใช้ (IndexedDB) ไม่มีเซิร์ฟเวอร์ ไม่มีการอัปโหลด

## ไฟล์ที่รองรับ

| ชนิด | นามสกุล | หมายเหตุ |
|---|---|---|
| หนังสือข้อความ | `.epub` `.txt` `.md` `.html` | ปรับฟอนต์ ขนาด ระยะบรรทัด ธีมได้ · TXT รองรับ UTF-8 และ TIS-620 |
| PDF | `.pdf` | อ่าน ค้นหา ฟังเสียง ขีดเขียน จัดการหน้า ส่งออก |
| การ์ตูน | `.cbz` `.zip` `.cbr` `.rar` `.cb7` `.7z` | CBR/RAR/7z ถูกแตกเป็นอัลบั้มตอนนำเข้า |
| รูปภาพ | `.jpg` `.png` `.webp` `.gif` `.avif` `.bmp` (`.heic` เฉพาะ Safari) | เลือกหลายรูป/ทั้งโฟลเดอร์ → หนึ่งอัลบั้ม เปิดเป็นมุมมองโฟลเดอร์ |

ไม่รองรับ: ไฟล์ติด DRM (Kindle, MEB, Ookbee ฯลฯ), MOBI/AZW3, EPUB แบบ fixed-layout และ EPUB ตัวอักษรแนวตั้ง

## ฟีเจอร์

- เปิดหน้าได้ 2 แบบ: ปัดซ้าย–ขวา หรือเลื่อนบน–ล่าง (ตั้งแยกรายเล่ม)
- เอฟเฟกต์พลิกหน้าแบบม้วนกระดาษตามนิ้ว (เลือกแบบเลื่อน หรือปิดได้)
- โหมดมังงะ ขวา→ซ้าย และสองหน้าคู่ (อัตโนมัติบนจอกว้าง/จอพับ หน้าปกแสดงเดี่ยว)
- โหมดถนอมสายตา: ธีม 7 แบบ + กำหนดสีเอง, แสงอุ่น, หรี่แสง, คอนทราสต์, ขาวดำ, กลับสี, ย้อมหน้ากระดาษ, บันทึกเป็นชุดของตัวเองได้
- ชั้นหนังสือ จำตำแหน่งล่าสุด ที่คั่นหน้า ไฮไลต์ 4 สี + โน้ต สารบัญ ค้นหาในเล่ม
- อ่านออกเสียง (ใช้เสียงของเครื่อง เลือกภาษาไทย/อังกฤษ/ญี่ปุ่น/จีน/เกาหลีอัตโนมัติ)
- เตือนพักสายตา 20/30/45 นาที และเปิดจอค้างขณะอ่าน
- ซูมด้วยสองนิ้ว หรือแตะสองครั้งกลางจอ (PDF จะวาดใหม่ให้คมชัดเมื่อซูม)
- แก้ไข PDF: ปากกา ปากกาเน้นข้อความ ใส่ข้อความ ยางลบ · หมุน ลบ สลับลำดับหน้า · รวมไฟล์ PDF/รูป · ส่งออกเป็น PDF ใหม่

## วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่ (เช่น `eazy-reader`) แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ไว้ที่ราก (root) ของ repo
2. ไปที่ **Settings → Pages** เลือก **Deploy from a branch** → `main` / `(root)` แล้วกด Save
3. รอราว 1 นาที แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/eazy-reader/`

ไม่ต้อง build ไม่ต้องติดตั้งอะไรเพิ่ม ทุกไลบรารีอยู่ใน `vendor/` แล้ว

### ติดตั้งลงเครื่อง

- **iPhone / iPad:** เปิดด้วย Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
  (ควรติดตั้ง เพราะ Safari อาจล้างข้อมูลของเว็บที่ไม่ได้เปิดนานเกิน 7 วัน ถ้าไม่ได้เพิ่มไว้ที่หน้าจอโฮม)
- **Android / Galaxy Fold:** เปิดด้วย Chrome → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

### อัปเดตแอปหลังแก้โค้ด

แก้เลขเวอร์ชันบรรทัด `const VERSION = 'eazy-reader-v1'` ใน `sw.js` ทุกครั้งที่ deploy
(แอปใช้ไฟล์ในเครื่องก่อนแล้วอัปเดตเบื้องหลัง ผู้ใช้จะเห็นของใหม่เมื่อเปิดครั้งถัดไป)

### ทดสอบในเครื่อง

```
python3 -m http.server 8000
```
แล้วเปิด `http://localhost:8000` (เปิดจากไฟล์ตรง ๆ แบบ `file://` ไม่ได้ เพราะใช้ ES modules)

## โครงสร้าง

```
index.html            หน้าเดียวของแอป
css/app.css           สไตล์ทั้งหมด
js/app.js             ชั้นหนังสือ แถบเครื่องมือ การตั้งค่า
js/importer.js        ตรวจชนิดไฟล์และนำเข้า
js/sources.js         ตัวเปิด PDF / รูป / EPUB / TXT
js/fixedview.js       ตัวอ่านหน้าคงที่ (PDF รูป การ์ตูน)
js/reflowview.js      ตัวอ่านข้อความไหล (EPUB TXT)
js/flip.js            ท่าทางนิ้วและเอฟเฟกต์พลิกหน้า
js/pdfedit.js         ขีดเขียนและสร้าง PDF ใหม่
js/tts.js             อ่านออกเสียง
js/db.js              IndexedDB
sw.js                 service worker (ออฟไลน์)
vendor/               pdf.js, pdf-lib, zip.js, libarchive.js
fonts/                Sarabun, Noto Serif Thai
```

## ข้อจำกัดที่ควรรู้

- ทดสอบอัตโนมัติด้วย Chromium ที่ขนาดจอมือถือ จอพับ และเดสก์ท็อป ยังไม่ได้ทดสอบบน iPhone และ Galaxy Fold เครื่องจริง
- การอ่านออกเสียงขึ้นกับเสียงที่ติดตั้งในเครื่อง (ต้องมีเสียงภาษาไทยจึงอ่านไทยได้)
- แก้ข้อความเดิมในเนื้อ PDF ไม่ได้ · ลายขีดเขียนถูกฝังเป็นภาพโปร่งใสตอนส่งออก · PDF ที่ตั้งรหัสผ่านอ่านได้แต่ส่งออกไม่ได้
- CBR/RAR/7z ถูกโหลดทั้งไฟล์เข้าหน่วยความจำตอนนำเข้า ไฟล์ใหญ่มาก (หลายร้อย MB) อาจล้มเหลวบนมือถือ
- iPhone เลือกทั้งโฟลเดอร์ไม่ได้ ให้เลือกหลายรูปหรือใช้ไฟล์ ZIP/CBZ แทน
- ค้นหาใน PDF จะพาไปที่หน้า แต่ไม่ไฮไลต์คำในหน้า · PDF สแกนเป็นภาพค้นหา/ฟังเสียงไม่ได้
